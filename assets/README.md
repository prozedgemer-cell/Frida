# Frida static seed images

Drop reference photos here. They are served as static files by the PWA
(GitHub Pages: `https://prozedgemer-cell.github.io/Frida/assets/...`).

Folders:

- `outfits/` — outfit lookbook / clothing references
- `sex-straf/` — fictional RP mood images for the Sex-straf tab
- `profile/` — Frida profile / body-reference shots

After adding files, list them in `src/data/seedImages.ts` so the UI shows them
(filename + Danish caption). User-uploaded photos live in IndexedDB on-device
and are **not** this folder.

Keep everything 18+ and Frida-persona compliant (femme; no vaginal-use imagery
as the commanded act).
